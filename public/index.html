Aplicación de Pruebas de Conocimiento Cero en la Autenticación mediante Sum-Check

El sistema desarrollado es una construcción ZK-like que ilustra cómo un usuario (Prover) puede probar conocimiento de un secreto (contraseña) ante un tercero (Verifier) sin enviarlo directamente.

Se trata de un prototipo didáctico de autenticación basado en la aplicación de técnicas del paradigma de conocimiento cero, concretamente el protocolo de Sum-Check y su transformación de Fiat-Shamir para eliminar la necesidad de interacción en tiempo real. Además se proporciona una extensión experimental de compromiso polinomial para ilustrar la identidad algebraica de apertura.

Protocolo base Sum-Check
Modo opcional Fiat-Shamir
Extensión Compromiso polinomial
