Registro de usuario y generación de credenciales

En la fase de registro, el usuario proporciona un nombre de usuario y una contraseña. El sistema genera los datos de verificación necesarios para la verificación de la autenticación sin revelar la contraseña.

Únicamente viajan al servidor los datos de verificación, mientras que la contraseña permanece en el lado del cliente dentro del alcance didáctico del prototipo.

01
Contraseña a bits

La entrada se convierte en una secuencia binaria de longitud fija.

02
Tabla de evaluaciones

Los bits se combinan con pesos públicos sobre el cuerpo finito.

03
Datos de verificación

Se almacenan el claim, valores finales y el compromiso polinomial.

Alta de usuario

Crear credenciales de usuario

Selecciona el tamaño de la contraseña y registra un usuario para generar la instancia algebraica asociada a la autenticación.

Parámetros

Tamaño de contraseña

Registro
La contraseña debe tener exactamente el número de bytes seleccionado y contener solo caracteres ASCII. Los tamaños grandes están pensados para pruebas de rendimiento.
La contraseña nunca viaja al servidor, se utiliza en el lado del cliente para generar los parámetros de verificación.
